# 수집 실측 원장 계약

LetsHub는 실행 성공만으로 수집 건수를 표시하지 않는다. 수집기 완료 시 아래 형식의 원장을 제공한 서비스만 오늘·전일·주간 추이에 반영한다.

```json
{
  "run_id": "service-20261120-001",
  "observed_at": "2026-11-20T01:00:00Z",
  "stages": { "collect": { "status": "success", "ok": 120 } },
  "counts": { "records": 120 }
}
```

- `run_id`는 실행마다 고유해야 한다.
- `observed_at`은 수집 완료 시각이다.
- `count`는 설정 목표가 아닌 실제 저장 완료 건수다.
- 실패·진행 중·건수 미보고 실행은 수집량에 합산하지 않는다.
- 증분 누적이 필요한 서비스는 별도 `increment` 원장을 제공한다. 전체 스냅샷 수치를 누적값으로 더하지 않는다.

NewsBoard는 공개 관측 원장의 `vote_rows`를 이미 이 계약으로 연결했다. 나머지 서비스는 동일한 원장을 노출한 뒤 LetsHub 수집원에 등록한다.
