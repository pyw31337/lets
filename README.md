# Let's Master Control Hub (렛츠 통합 관제 대시보드)

**Let's Master Control Hub (`pyw31337/lets`)**는 `pyw31337` 산하 15대 전체 마이크로서비스의 수집과 분석, 품질관리 자동화의 데일리 현황 흐름을 한눈에 일목요연하게 조망하고 통합 관제할 수 있는 **중앙 마스터 관제 대시보드**입니다.

## 🌐 주요 관제 기능
1. **데일리 수집 & 품질관리 자동화 현황 흐름 (핵심 시각화)**:
   - 14일간의 일일 수집량 추이(바 차트) + 7일 이동평균선 + 품질 건강점수 SVG 시계열 복합 차트.
   - 6대 핵심 서비스별 원장 규모 비중(도넛 차트).
2. **자가진화(Self-Evolving) 이상징후 감시**:
   - `ZERO_DROP`(수집량 0 수렴) 및 `FLAT_CURVE`(수집 정체) 100% 무사고 실시간 관제.
3. **6대 플래그십 코어 관제**:
   - **렛츠피플 (`pyw31337/people`)**: 인물 17.1만명, 미디어/PD/작가 전 생애 연대기 & 케미스트리, 역사 거장
   - **렛츠로 (`pyw31337/law`)**: 법률·판례 4.3만건, 한문철식 교통사고 3D 시뮬레이터, 계약서 독소조항 AI 스캐너
   - **렛츠인슈 (`pyw31337/insu`)**: 46개년 전수 약관 2.8만건, 손해사정 면책 반박기, 자동차보험 합의금 계산기
   - **렛츠에셋 (`pyw31337/asset`)**: 100년 금융 시계열 15.8만 노드, 10대 위기 몬테카를로 스트레스 테스터, 3단계 절세 가이드
   - **렛츠아트 (`pyw31337/art`)**: 세계 명화 1.8만점, 고전 문학 6.2천편, 3D 액자 시뮬레이터, 큐레이터 도상학
   - **컬처플로우 (`pyw31337/culture`)**: 공연/전시/뮤지컬 1.4만건, KOFIC/KOPIS 연계
4. **확장 9개 패밀리 서비스군 통합 매핑**:
   - 전국캠핑(`camp`), 도로CCTV(`cctv`), 헤어뷰티(`hair`), 모여라달력(`calendar`), 렛츠픽(`pick`), 렛츠바이(`buy`), 미트플레이스(`meat`), 수도권지하철(`subway`), 렛츠뉴스(`news`).
5. **관리자(Admin) 권한 모드**:
   - 마스터 패스워드 인증을 통한 파이프라인 수동 즉시 강제 트리거 및 이상징후 임계치(Threshold) 조정 지원.
6. **디자인 테마**:
   - 정갈하고 선명한 **프리미엄 라이트(Light Theme)** 기반 UI/UX.
